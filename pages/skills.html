THE TOOLS BEHIND THE WORK

my skills

A practical toolkit for investigating, designing, building, and validating.

Explore the skills. Hover, tap, or use the keyboard to read what I actually do.

technical investigation

I investigate crawl, indexing, CMS, and live-page discrepancies by checking the available evidence before deciding what caused them.

information architecture

I organize complex websites into understandable page hierarchies, with clear relationships between offices, services, and supporting content.

url migration

I map old and new URL structures, review redirects, and check whether navigation and internal links point where they should.

root cause analysis

I test competing explanations, keep documented findings separate from hypotheses, and say when a cause is still unknown.

responsive design

I build layouts that adapt to different screens, then check whether navigation and content remain usable on mobile.

html

I write semantic HTML for clear page structure, accessible content, and maintainable websites.

user experience

I review how people move through a website and look for confusing navigation, missing context, and unnecessary friction.

css

I style responsive interfaces, create interactions, and refine typography, spacing, and layout by hand.

screaming frog

I use crawl exports to examine page structure, status codes, internal links, canonical signals, and differences across URLs.

figma

I use Figma for wireframes, layouts, visual planning, and reviewing how interface components work together.

wordpress & acf

I examine WordPress pages, custom fields, templates, and saved versus publicly rendered content when validating site changes.

data reconciliation

I compare crawl data, Google Search Console, CMS records, exports, and change logs to find discrepancies.

technical qa

I record what was changed, what was checked, and which issues remain open after implementation.

ai workflows

I design AI-assisted research and investigation workflows with evidence checks, human review, and approval gates.

wireframing

I plan page relationships and user flows before building so the structure makes sense beyond the screen design.

javascript

I use JavaScript to add front-end behavior and interactions to my hand-coded web projects.

front-end development

I build and maintain web interfaces using HTML, CSS, JavaScript, responsive layout, and accessibility basics.

google search console

I examine page and query performance, indexing records, inspection results, and changes over time as investigation evidence.

git & github

I work with branches, version history, and GitHub repositories to track and review code changes.

creative design

I use tools such as Photoshop, Canva, and Midjourney to produce and refine visuals for digital projects.
