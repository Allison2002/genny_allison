Original web development project

The performance work on Sports Tube was one of my favorite technical exercises. I worked through page structure, images, and loading behavior, then tested the changes with PageSpeed Insights.

This project began with a mobile score of 71 and a desktop score of 96. Through a comprehensive rebuild, I brought both to a perfect 100/100—a result of combining AI-powered content creation with performance-focused web development.

(These are historical PageSpeed screenshots. Current scores may differ by test date, page, and device.)

  • Created lightweight, custom visuals using AI tools to balance design and speed.
  • Refined and cleaned up code to eliminate performance bottlenecks.
  • Optimized all content for search engines using advanced on-page and technical SEO strategies.
  • Improved Core Web Vitals by reducing render-blocking resources and stabilizing layout shifts.

The project taught me how much image size, layout choices, and front-end code can affect the experience.

I use that same test-and-revise process in the websites I work on now.
