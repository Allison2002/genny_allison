project 3 | the website

sports tube community

Original web development project

Sports Tube Community is a companion to the Sports Tube Video Blog. I designed it around a different idea: an article-based community layout where users could browse sports stories and see how submissions might be organized.

I worked on the responsive layout, content structure, navigation, and image delivery. The design uses CMS-style page patterns; that does not mean this demonstration has a complete live publishing backend.

ChatGPT helped with draft copy, and I used Midjourney and Canva for visuals. I planned layouts in Figma and refined the front-end experience myself. Historical PageSpeed testing is documented separately on the Grade page; the scores are not guaranteed today.

The site is hosted on Netlify, with Cloudinary used for imagery. This project shows my approach to planning a user journey and building a consistent interface around it.
